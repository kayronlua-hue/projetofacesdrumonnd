# Faces de Drummond

Versão preparada para publicação no Netlify com o mesmo visual do site atual.

## Publicar no Netlify

1. Escolha **Add new site** e depois **Import an existing project**.
2. Conecte este repositório do GitHub.
3. Não informe comando de build.
4. O diretório de publicação já está configurado como a raiz do repositório.
5. Selecione **Deploy site**.

O arquivo `_redirects` mantém imagens, estilos, revistas, APIs e o painel administrativo ligados à versão principal do projeto.
