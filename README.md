# Faces de Drummond

Site informativo estudantil preparado para publicação no Netlify, preservando a aparência da versão atual.

## Publicação

1. No Netlify, selecione **Add new site** e **Import an existing project**.
2. Escolha este repositório do GitHub.
3. Não informe comando de build.
4. O diretório de publicação já está configurado como a raiz do repositório.
5. Selecione **Deploy site**.

Imagens, estilos, fontes e páginas estão incluídos neste repositório. O painel administrativo, os dados enviados e o PDF editorial maior continuam conectados ao serviço principal.
